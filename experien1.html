HOW IT STARTED

Curiosity became
momentum.

I started by wondering how websites work. HTML and CSS made it possible to make an idea visible; problem-solving made me want to go deeper.

The spark

Creating simple pages showed me that web development is both creative and analytical. The more I practised, the more I enjoyed turning a blank screen into something functional, responsive, and useful.

LEARNING PATH

One layer
at a time.

Each step added a new capability: from making an interface to connecting it with a resilient, useful backend.

  1. HTML & CSS

    Learned responsive layouts, landing pages, and portfolio websites through hands-on frontend practice.

  2. JavaScript

    Expanded into DOM manipulation, ES6, asynchronous programming, APIs, and interactive website behavior.

  3. React.js

    Started building reusable components, managing state, and designing single-page applications.

  4. Node.js & Express

    Learned to create REST APIs, server-side applications, and authentication systems.

  5. MongoDB

    Worked with data storage, retrieval, and application data management.
